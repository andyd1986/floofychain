# 🌟 FloofyChain (FLOOF) Coin 🌟

FloofyChain (FLOOF) is a decentralized cryptocurrency built on the Scrypt-AuxPoW algorithm. It combines Proof-of-Work (PoW) with Auxiliary Proof-of-Work (AuxPoW) to support mining security and decentralization.

FloofyChain uses a simple mining-based reward model with scheduled multiplier reward events. There is no transaction tax, no burn fee, and no developer fee. The focus is on clear block rewards, recurring event periods, and community involvement as the chain grows.

## 🎉 Rewards System

FloofyChain rewards miners through block rewards.

The chain also includes scheduled multiplier reward events. These events are staged every 20,000 blocks and last for 4,999 blocks.

During a multiplier event, mining rewards are boosted according to the active event rules. Once the event period ends, the chain returns to the standard reward cycle until the next scheduled event.

After block 500,000, multiplier event direction becomes community-voted, giving the community more influence over future reward events.

---

## 🗳️ Community Voting

After block 500,000, FloofyChain moves toward community-voted multiplier events.

This allows the community to help guide future event direction and gives long-term participants a stronger voice in how reward events develop over time.
